MINOCHAT ДЛЯ ANDROID (настоящее приложение: Capacitor, интерфейс вшит внутрь APK)

Собрать APK здесь я не мог (нет Android SDK), поэтому сборка идёт в облаке GitHub - бесплатно, ничего ставить не нужно.

СПОСОБ 1 - GitHub (рекомендую)
  1. Зайдите на github.com, войдите (или зарегистрируйтесь) -> New repository -> имя minochat -> Create.
  2. На странице репозитория: "uploading an existing file" -> перетащите ВСЁ содержимое этой папки
     (включая скрытую папку .github - если проводник её не показывает, включите "Скрытые элементы").
     Если .github не загружается перетаскиванием: Add file -> Create new file -> имя
     .github/workflows/build-apk.yml -> вставьте содержимое из файла в архиве -> Commit.
  3. Вкладка Actions -> Build MinoChat APK -> Run workflow (зелёная кнопка). Ждите 5-8 минут.
  4. Откройте завершённый запуск -> внизу Artifacts -> MinoChat-APK -> скачается zip с MinoChat.apk.
  5. Перекиньте MinoChat.apk на телефон и откройте. Разрешите "установку из неизвестных источников".

СПОСОБ 2 - Android Studio (если она у вас стоит)
  В папке выполните: npm install, npx cap add android, python scripts/android-setup.py, npx cap sync android,
  npx cap open android -> Build -> Build APK(s).

ЧТО УМЕЕТ
  - Свой значок MinoChat, запуск без браузерной адресной строки.
  - Микрофон, камера, звонки (при первом звонке Android спросит разрешения).
  - Системные уведомления, пока приложение не выгружено из памяти.
  - Кнопка "назад" закрывает окна и чат.
  - Те же 112 функций, что на сайте.

ОГРАНИЧЕНИЯ
  - APK подписан отладочным ключом: ставится нормально, но в Google Play с ним выкладывать нельзя.
  - Play Protect может предупредить о неизвестном приложении - выберите "Всё равно установить".
  - Уведомления, когда приложение полностью закрыто, не приходят (для этого нужен платный Firebase Blaze).
  - Вход через Google не настроен, используйте почту и пароль.

UPLOAD.BAT (самый простой способ)
  1. Положите скачанный google-services.json рядом с upload.bat (из Firebase: Project settings - Your apps - Android).
  2. Установите Git (git-scm.com), если ещё не стоит.
  3. Дважды щёлкните upload.bat (первый раз попросит войти в GitHub). Он сам заменит всё в репозитории и запустит сборку.
     Старую вложенную папку minochat-apk-project он удалит - так и надо.


УВЕДОМЛЕНИЯ ПРИ ЗАКРЫТОМ ПРИЛОЖЕНИИ (3.5): в шторке появится тихий значок 'MinoChat работает в фоне' - это служба, которая держит связь с чатами. Кнопка 'Выключить' в нём отключает её до следующего запуска приложения. При первом запуске Android спросит про экономию батареи - нажмите 'Разрешить'. На Xiaomi/Huawei/Tecno/Honor дополнительно: Настройки -> Приложения -> MinoChat -> Автозапуск ВКЛ, Батарея -> Без ограничений.
Если вы смахнули приложение из списка недавних, на части телефонов служба тоже останавливается - это ограничение производителя.


АВТООБНОВЛЕНИЕ САМОГО ПРИЛОЖЕНИЯ (3.7) - как выпускать новый APK:
 1. Поднимите версию в package.json (например 3.8.0) и запустите upload.bat.
 2. Когда сборка в GitHub Actions закончится, скачайте артефакт MinoChat-APK и распакуйте.
    В нём два файла: MinoChat.apk и apk.json.
 3. Положите ОБА файла в папку сайта public\ (рядом с index.html) и запустите deploy.bat сайта.
 4. Все телефоны с приложением 3.7 и новее сами заметят новую версию, скачают https://speeky-a0653.web.app/MinoChat.apk
    и покажут системное окно 'Обновить?' - достаточно нажать 'Обновить'.
Первый раз Android попросит разрешить MinoChat устанавливать приложения - разрешите.
Версию 3.7 нужно поставить на каждый телефон вручную один раз (дальше само).
Тихо, вообще без нажатий, Android обновить обычное приложение не позволяет - окно подтверждения обязательно.


RuStore: APK теперь собирается как РЕЛИЗ (не debug) - RuStore принимает только такие.
Ключ подписи тот же (minochat.keystore), поэтому вход через Google и обновление поверх старой версии работают как раньше.
